# Vera Clear Preview Package

An AI teammate with an indestructible laptop, ready to handle your work for you.

Open `index.html` in a browser to see every pet state animated.

Folders:

- `gifs/zoom/`: large share-friendly GIFs.
- `gifs/actual/`: app-size GIFs, about 113 x 122 px.
- `gifs/transparent/`: source-cell transparent GIFs, 192 x 208 px.
- `assets/`: contact sheet, spritesheet, and pet manifest.

The GIF timings follow the Codex avatar runtime frame timing used by the desktop overlay.
